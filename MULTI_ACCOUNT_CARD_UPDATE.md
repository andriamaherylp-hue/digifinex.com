
# Multi trading account update

Cette version prépare l'affichage administrateur par cartes séparées.

Principe:
- une carte = un compte de trading;
- plusieurs comptes peuvent être affichés simultanément;
- chaque compte est traité individuellement;
- le résultat Gain/Perte reste une décision manuelle de l'administrateur;
- le prix de clôture est saisi par compte.

Le backend existant TradingAccount et TradeOrder est conservé.
